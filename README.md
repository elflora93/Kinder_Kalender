# Kinder-Kalender

Ein Kalender für Vorschulkinder: Wer bringt in die Kita, wer holt ab, was ist am Nachmittag, wer bringt ins Bett – mit Fotos, Symbolen und einer Zeitleiste mit Tageszeit-Bildern.

- `index.html` – die Web-App (aktuell Prototyp, Daten werden nur lokal auf dem Gerät gespeichert)

Geplant: Daten in Supabase, Anbindung an Google-Kalender, Anzeige als Web-App auf dem iPad und auf einem Wand-Monitor.
